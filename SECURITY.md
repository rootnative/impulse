# Security policy

## Supported versions

Impulse is pre-`1.0.0`. Only the latest release receives security fixes.

| Version                             | Supported |
| ----------------------------------- | --------- |
| `@rootnative/impulse`, latest release | Yes       |
| Older releases                      | No        |

Nothing is published yet, so there is no supported release today.

## Report a vulnerability

Do not open a public issue for a security problem.

1. Open the [Security tab](https://github.com/rootnative/impulse/security/advisories/new) of this repository.
2. Select **Report a vulnerability** and fill in the private form.
3. Give the affected version and the steps to reproduce.

We reply within 7 days. We publish a fix and an advisory after we confirm the report.

## Scope

Impulse runs inside your React Native app and has no network or server component. Reports about the example app are welcome, but they are lower priority than a defect in the published package.
